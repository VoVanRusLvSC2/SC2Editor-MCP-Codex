ui.preview: real map markup

The team reads its own SC2Layout, uncovers Core templates, resolves assets aliases and font styles, and creates PNG, standalone HTML, and JSON with diagnostics. The editor and game didn't run.

Our map panel · In the background of the mini-card · Full report

Take Agria_Vasya_Fedya_Native_v6: 16 elements, 12 CASC DDS. The dialog size of 350×142 and the top indentation of 35 match the DialogCreate constants in MapScript. Signatures and 00:55 are clearly set as a test state. Minimap.tga is used against the background of the map, not a 3D game frame.

Maintained

  • Common images; packed Border 4×8; HorizontalBorder 10×1; EndCap; NineSlice 40/20/40; tiled edges and fill.
  • Up to four layers, LayerVisible, LayerColor/Alpha, alpha-only mask, AlphaChannel, inverse channels and AlphaChannelMultiply.
  • Color, Alpha, IgnoreParentColor/Alpha; Colorize, Desaturate, Fill and AddSelf; common alpha overlay and approximate Multiply/Add/Subtract/Lighten/Darken.
  • Textural coordinates, own and heritable styles, shadows/contour of text, parent/sibling anchors, RenderPriority, visibility and selection of racial Defines.
  • Links are checked for cycles; unknown parameters, unavailable resources and possible overlapping of inscriptions are indicated in the report.

Limits of accuracy

This is a static approximate renderer, not an SC2 engine. Native class defaults of priorities are not restored; Arial is used instead of an exact set of game fonts. Galaxy, UI animations, states and bindings do not run. Circular, rotation/skew, full rich text markup, complex virtual frames and native clipping are not yet reproduced. Mapping AdjustmentColor on shader uniforms and unusual BlendMode require in-engine verification; explicit DarkAdjustColor/LightAdjustColor reduces uncertainty.

Checking the current timer found candidates for StandardSmallPanelTemplate decor overlap, and on PNG, it's noticeable. The report doesn't say it's a confirmed game error: part of the defaults and the metric remain approximate.

Parameter diagram: schema/upstream/enum.xml and frame_class.xml. TextureType Community Description, checked with real atlases. PNG/text raster: sharpOriginal game shaders/textures are not included in Git; there is no publication on GitHub.

Performance and API

One MCP command, short JSON with links; PNG and pixel arrays are not turned on in response. The map-builder tool is turned on on on request via modkit.enable_tools. Renderer/sharp loads lazily. CASC reuses verified build/SHA byte caches. .sc2mcp-ui-preview is excluded from the map and Git.
