What has been corrected in this review

Milliseconds have become the standard time base (1000 ticks/s); explicit ticksPerSecond remains override. In the absence of the scalar curve type, Linear is used. The animated Game Camera now recalculates the eye from Yaw/Pitch/Distance and target/heightOffset. Target Camera supports independent eye/target and lifetime. Bookmark events perform a local jump/pause; End Scene completes the cycle by preserving the remainder of the step. There is protection against endless transitions.

Fade is executed by GPU pass, gets into the saved frame and software PNG; the general evaluator takes into account the amount/unfadedAmount, fadeIn/out, priority and hold. Added geometry Opacity/Tint/Height Offset. Timeline shows bookmarks, End Scene and Fog/Light/RTT/Fade, supports I/O, Alt+I/O, loop selection, Shift+PageUp/Down and D for Director.

Links, linking, filters, terrain snap and DOF are no longer ignored silently: the report gives out diagnostics. cutscene.coverage; it is included through modkit.enable_toolsThe initial MCP window still contains 6 tools.

queue for full support

  1. Semantics scene evaluation: start/end links with localized duration; live reference resolver; filters/guide/game-mode; Active For Shot; timed attachments with M3 attachment points and cycle detection; path and gaze constraints.
  2. Director Environment Light/Active Light with mixing; all types of tangent curves with confirmed native IDs; Play Once/Forever/Right-Aligned and automatic movespeed; explicit M3A + non-bone tracks.
  3. Sound and master audio clock, World Text/markup, Conversation import/driver/subtitles and FXA. Sound/Conversation/Actor catalog and localization resolution are needed to match.
  4. Viewport authoring, multi-selection/copy-paste/undo, compatible node types, manipulator/AutoKey/curve editor, Ghost and overlap rules, split/NLE/import/reference workflows.
  5. Map terrain/FOW, shadows, AO, HDR/colorization, DOF, depth blend/distortion/volume and other M3 material/effect flags; native RTT story-mode behavior.
  6. A deterministic set of golden scenes/SC2 frames for comparison. Without it, you can prove the contracts of our implementation, but not the complete match of the engine.

No queue item counts just because of the ability to serialize XML. Each requires an evaluator, behavioral regression test, and appropriate visual confirmation.
