# Результат разработки — alpha.12

Порядок: основа карты → Terrain → Galaxy-скрипты → проверка в редакторе и игре. GUI-триггеры исключены из разработки; существующие компоненты чужих карт сохраняются.

Выполнено: девятый модуль Map с 11 командами; нативный MPQ backend на закреплённой StormLib; импорт, проверенный экспорт и клонирование сценария; ограниченное редактирование MapInfo v39 с сохранением неизвестного хвоста; persistent recovery journal и межпроцессная блокировка. Неподтверждённая запись водоёмов отключена.

Проверки: 220 тестов PASS, 0 ошибок и пропусков; build/lint PASS. Четыре оригинальные карты прошли полный roundtrip 939 пользовательских записей с SHA-256 проверкой. Реальное прерывание тестовых процессов проверило восстановление незавершённой группы; внешние изменения блокируют восстановление до записи. Portable MCP/HTTP smoke прошёл на Linux Node: 139 инструментов, девять модулей, Map capabilities и совместное сохранение UI.

Windows helper скомпилирован и проверен как x64 PE, но на Windows не запускался. Node 20+ требуется отдельно. Редактор и игра не запускались; визуальная проверка GUI не выполнялась.

Остаются: чистая карта с нуля и подтверждённые DocumentHeader/player/variant/defaults; Terrain init/resize/derived, cliff/ramp/water/pathing writers, vertex colors; отдельный script.* модуль. Клон сценарной карты не является новой пустой картой. Power-loss certification и универсальная фиксация всех directory/dependency reads вне Map не выполнены; drafts и Undo остаются в памяти процесса.

Следующий блок — восстановить минимальные нативные defaults и проверенный чистый blueprint, затем реализовать Terrain init и согласованную перестройку derived-компонентов. Для неподтверждённых water/pathing форматов нужны нативные образцы или восстановленный код сериализации: имеющийся EXE пока не дал подтверждённых instruction xrefs.

Подробные JSON-доказательства и логи включены в generated/, план и описание команд — в docs/.
