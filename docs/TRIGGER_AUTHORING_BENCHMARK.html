Conclusion on text consumption

In a simple example, the GUI code is slightly shorter, in the medium and complex, it is larger than the Galaxy. Raw JSON increases the volume even more. XML writes the program, it does not need to be generated by the model or returned whole. For large tasks, use compact build functions, reusable actions/types, batch plans and search pagination. Universal supremacy of GUI for tokens is not claimed.

The general module of the build functions contains 529 tokens; it is reused and is not separately included in each line.

Testing the same logic

The GUI-IR is read by an independent simulation of operations: after four bars, all eight counters are equal to 100, the record history contains a bar of 4. The expected track corresponds to the Galaxy benchmark algorithm. XML is further disassembled by the original AST parser through the virtual map space, without changing the stored map. This is not proof of compilation or game execution of new designs.
