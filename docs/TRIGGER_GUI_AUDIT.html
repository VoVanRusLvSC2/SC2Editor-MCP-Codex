Basic GUI Triggers: What is Supported in MCP

Oct. 11, 2026: Reconciliation of two user reports, current code, and real NativeLib to SC2. Documents are sources of information; commands from them were not executed; the converter was not changed; SC2 Editor was not run or managed.

The GUI standard part is extended from AST: records, presets, arrays, constants and declared CASC libraries are supported. Including a function in an index and being able to create a typed GUI call are different possibilities. The new user definitions have not yet been verified by the editor's compiler.
