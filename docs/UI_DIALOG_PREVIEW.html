ui.preview_dialogs

Supplement to ui.preview: preview from Dialog/Dialog Item of Galaxy calls and from this GUI Triggers graph. Converter is not used, game APIs and code are not executed.

A panel from the Galaxy · Same panel from GUI. · Dialog Item without SC2Layout · Corrected v7 card

What reads.

DialogCreate, size/position/visibility/transparency, creating Label/Image/Panel and template panels, hookup of child elements, Text/Style/Image/Image/ImageType/Tiled/Color/BlendMode properties. Standard GUI wrappers are read directly from the local NativeLib. Text is taken from the selected localization; Style from its own FontStyles and its inheritance. BlizzardGlobal/Eurostile game fonts from CA fallback are used.

The entrypoints that create/configure the interface are selected. Simple values, variables, arithmetic, bool branches, parameters and assistant returns are resolved statically. Unknown conditions, cycles, unread groups of players and unsupported UI APIs are diagnosed. A full-fledged Galaxy VM, timers and events are not triggered. TimerGetRemaining and similar dynamic calls are set explicitly in snapshot calls.

Corrections

  • In Border, the vertical thickness is taken from the height of the atlas strip, not the width of the angular cell, which eliminates the incorrect geometry on the rectangular texture of 216×320.
  • In v7, the large internal angles/pattern decor are hidden; the inscriptions have RenderPriority 600 and remain in the original dialog 350×142.
  • GUI implicit text Param without Value now generates StringExternal (“Param/Value/Id”) as a localized GUI graph. The apparent empty Value remains empty. This corrects the loss of headers and messages when assembled outside the editor.
  • Runtime Dialog Item sizes take precedence over inherited anchors. Different states are saved to different preview files.
  • Font files materialize immutably; repeated preview does not attempt to overwrite a font opened by Pango.

Checks.

56 target tests PASS, TypeScript/ESLint PASS. GUI, Galaxy and SC2Layout panels gave the same PNG at the same state: SHA256 1b96f61273ddba851f2f859c119cf3590ecebaa6d3866c8beac62837a733068a. Direct Dialog Items example is also created and viewed. Map v7 is packaged and archive reopened.

Real MCP call via bundled Windows Node: PASS. First preview 4633 ms, repeat 383 ms. Initial map-builder tools are 58; ui.preview_dialogs is enabled via modkit.enable_tools. 41 text tokens of arguments and 569 responses (o200k_base) are measured. This is not a full model expense: reasoning, system, schemas and images are not included here.

For Galaxy: format="galaxy", file="MapScript.galaxy". For GUI: file="Triggers". The list of functions is taken from a real generated/existing source; names are not guessed.

Limits of accuracy

The engine/editor did not start. FontGroup and Pango hinting font selections remain approximate. UI animations, complex rich text markup, Circular and some native defaults are not restored. Button/other controls without explicit image/template display predefined content and boundaries with a warning that there is no exact native skin. The new PNG confirms the consistency of our sources, not a complete match with the game.
