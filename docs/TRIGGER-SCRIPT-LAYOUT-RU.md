# Custom Script и структура GUI-триггеров

SC2 Editor читает Custom Script действия как блок `ScriptCode` с отступом XML.
Если записать текст в строку с тегом или без структурного отступа, редактор может
срезать начало строк Galaxy. Валидный XML и проверка отдельного `.galaxy` этого
не обнаруживают.

`trigger.normalizeScriptLayout` приводит только текстовые блоки Custom Script к
формату редактора. По умолчанию выполняется предварительный просмотр (`dryRun`).
Для записи: `dryRun: false`, затем `trigger.save` с резервной копией.

Сохраняются категории, IDs элементов, ссылки и порядок действий. Выражения
`ScriptCode` в типизированных параметрах не обрабатываются. Уже утраченные символы
не восстанавливаются: для этого нужна неповреждённая резервная копия.

`trigger.graft` автоматически форматирует импортированные Custom Script блоки.
Существующие блоки целевого файла при копировании остаются неизменными.

Формат соответствует обработке `appendScriptCodeBlock` в локальном Trigger Revize.
Эта операция не запускает Galaxy → Triggers конвертацию и не подтверждает
компиляцию штатным компилятором SC2 Editor.
