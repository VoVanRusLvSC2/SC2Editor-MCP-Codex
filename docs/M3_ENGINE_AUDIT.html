Confirmed native example

Local Imperia_KSP_ViewAkademik.SC2Cutscene found RTTChannel=0 and CCutsceneElementRTTChannel with objectGUID, cameraIndex, aspectRatio and time windows. Found Fog with color/density/falloff/startHeight, fractional key times, and Spot Light type=2 with attenuationStart/range. This data is used as a structure rather than commands to execute. Parser now accepts fractional key times.

Blizzard Cutscene Management Confirms: RTT assigns the model camera to one of seven channels and runs in campaign/story mode. Conventional camera nodes for native RTT are not suitable. Direct camera-node binding in our renderer is left as a diagnosable preview extension; for compatible SC2, use embedded M3 camera.

Verification

Additionally, the real cutscene.compose and cutscene.preview adopted native XML with Fog/Point Light/RTT and the real camera-only M3: two models, two cameras, one Fog, one local light, one RTT window. Verification is saved in ENVIRONMENT_MCP_VERIFICATION.json.

On RTX 2070, WebGL fixture with this embedded camera, Marine, RTT screen, point light and Fog. Framebuffer 512×341 contains 37254 pixels of objects distinct from the background; RTT pass=1, fog density=.08 in the included interval, glError=0. Screen receiverect light and Fog.

41 targeted tests, TypeScript/ESLint PASS on verified source graph; genuine MCP recreates user players. CPU PNG shows surface + approximate Fog; live local lights, RTT and FX require WebGL. The original SC2Cutscene is non-rewritten.

The following passes for a result close to the engine

  1. Color/depth prepass: soft particles, depth blend, distortion and reflections.
  2. Shadow maps/SSAO and playable CLight HDR/tonemap/colorization.
  3. Volumetric/noise and terrain/creep/splat inputs.
  4. Batch visibility, material-node overrides, composite alpha/order and M3A scalar bindings.
  5. Golden-image comparison with custom SC2 frames on the same cameras/times; before that, engineValidated=false.

The actual model tokens are not available; schema/payload measurements are not billing. The expensive PNG stage is passed through snapshots=false. Large geometry/light/RTT arrays remain in local HTML and are not returned by MCP text.
