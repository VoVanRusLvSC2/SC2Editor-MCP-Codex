Preview of pictures in UI Triggers

Reads the real Triggers GUI graph through the existing emitter or selected Galaxy features. Editor and converter are not used. Test script changes/shots are performed by real JSON-RPC MCP calls.

Open pictures: 100–400%, background and boundaries · Hover · MCP verification

What's being supported

Image, picture of the usual Button, panels on SC2Layout template and Hookup. Textures are read from the map and installed game via CASC. Image/HoverImage, Color (Galaxy percentages), Alpha, AlphaMask, Desaturated/DesaturationColor, Rotation, RenderPriority, Width/Height, Tiled, ImageType/BlendMode (named and numerical values).Inheritance, layers, masks, and mixing use a common render of UI.Nord, Normal's, Normal's vertical, and non-statedex images.

HTML allows you to include element boundaries, light/dark/chess background, scale 100/200/400% and pixel mode. ui.preview_batch gives a comparative PNG; modkit.batch saves short links to individual images, without XML and full source.

GUI of your card

The original map has not been changed. A separate copy of Fixture has been used for verification; the demo script is not connected to InitMap.

Checks.

40 targeted tests PASS, TypeScript and ESLint PASS. Five real-world MCP snapshots; tested diagnostics of each: no lost textures, masks, styles or unsupported assigned properties.

Packet MCP call time: 8201 ms Argument text: 205 tokens; reply: 1,347 o200k_base tokens. This is only payload, not full model/thinking expense. The initial 6 workflow tools are saved.

Limits of accuracy

The static render does not run the game or Galaxy VM. Transitions, non-zero-duration fade, animations, unknown conditions/cycles, and Circular receive explicit diagnostic messages. Rotation is done clockwise around the center with cropping within the element boundaries; accurate engineping and font hinting require in-game comparison. DDS formats are decoded by existing decoder; unsupported format is not masqueraded as a successful image. engine Validated assets=false.
